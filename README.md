# Exploratory Data Analysis

A collection of notebooks and workshop materials for practicing exploratory data analysis and visualization.

## What's included

- Titanic dataset analysis
- Iris dataset analysis and advanced visualizations
- Movie-rating analysis
- General EDA notebooks and source datasets
- Workshop slides, notes, and a presentation on LLM-assisted EDA

The repository organizes projects into numbered folders. Open the notebook in a project folder to follow the analysis; source data and supporting material are stored beside the notebooks.

## Tools

Python · Jupyter Notebook · pandas · Matplotlib · Seaborn
